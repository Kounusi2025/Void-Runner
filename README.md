# Void Runner

降ってくる赤いブロックをよけて、コインを集めるブラウザゲームです。スマホでもPCでも遊べます。

**現在のバージョン: v1.1**(更新内容は [CHANGELOG.md](CHANGELOG.md) を見てください)

## 遊び方

- **赤いブロック**に当たるとゲームオーバー
- **コイン**は +50点。連続で取る(2.2秒以内)とコンボになり、倍率が上がります(最大×5)
- **シールド**(水色の丸いアイテム)を取ると、ブロックに1回だけ当たっても大丈夫。割れたあとは1秒間だけ無敵です
- 生き残るほど加点されます(1秒で +10点)
- 15秒ごとにレベルアップして、どんどん速くなります
- ブロックは落ちてくる少し前に、画面の上に赤い警告が出ます
- スコアに応じて **ランク**(ROOKIE → RUNNER → DASHER → PILOT → ACE → VOID MASTER)がつきます

## 操作方法

| 端末 | 操作 |
| --- | --- |
| PC | `←` `↑` `↓` `→` または `W` `A` `S` `D` で移動 / `P` ポーズ / `M` ミュート / `Space` スタート |
| スマホ | 画面のどこでも指をスライドして移動 |

## スコアをシェアする

ゲームオーバー画面のボタンから、結果を友だちに送れます。

| ボタン | できること |
| --- | --- |
| **X ポスト** | スコア・ランク・ハッシュタグ入りの文章で、Xの投稿画面を開く |
| **LINE** | 同じ文章をLINEで送る(スマホではLINEアプリが開きます) |
| **画像共有 / 画像保存** | スコア画像(1200×630)を作成。スマホでは共有メニューが開き、PCでは画像を保存します |
| **コピー** | 文章をクリップボードにコピー |

## 軽量モード

タイトル画面の右上にある `⚡ LITE` ボタンで切り替えられます。

- 光やパーティクル、画面の揺れ、フラッシュを減らして、動作を軽くします
- 動きがカクつく端末では、プレイ開始の数秒後に **自動で切り替わります**(`LITE AUTO`)

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る(例: `void-runner`)
2. このフォルダの中身(上の6ファイル)をリポジトリの一番上の階層にアップロードする
3. リポジトリの **Settings → Pages** を開く
4. **Source** を `Deploy from a branch`、Branch を `main` / `(root)` にして Save
5. 数分後に `https://ユーザー名.github.io/void-runner/` で遊べるようになります

### 公開したら必ずやること(シェア用プレビュー)

`index.html` の中の `YOUR-NAME` を、自分のGitHubユーザー名に書き換えてください(2か所)。

```html
<meta property="og:image" content="https://YOUR-NAME.github.io/void-runner/ogp.png">
<meta name="twitter:image" content="https://YOUR-NAME.github.io/void-runner/ogp.png">
```

書き換えると、XやLINEにURLを貼ったときに `ogp.png` が大きく表示されます。
(以前にURLを投稿していると、Xなどが古い表示を覚えていることがあります。数日たつと直ります)

## すでに公開している v1.0 を v1.1 に更新する手順

1. リポジトリのページで **Add file → Upload files** を開く
2. このフォルダの6ファイルをドラッグして、同じ名前のファイルを上書きする
3. 「Commit changes」を押す(メッセージ例: `v1.1: シェア機能・軽量化・シールド追加`)
4. 右側の **Releases → Create a new release** で、タグに `v1.1` を入力して公開する
   (説明文には `CHANGELOG.md` の v1.1 の部分をコピーすると便利です)

## カスタマイズ

`script.js` の先頭にある数値を変えると、遊びやすさを調整できます。

- `LEVEL_TIME` … 何秒ごとにレベルアップするか
- `COMBO_TIME` … コンボが続く秒数
- `SENS` … スマホの指の動きに対する自機の動きやすさ
- `SHIELD_FROM` … 何秒目からシールドが出るか
- `SHIELD_RATE` … シールドの出やすさ(大きいほど出やすい)
- `INVULN_TIME` … シールドが割れたあとの無敵時間(秒)
