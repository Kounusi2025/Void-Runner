# Void Runner

降ってくる赤いブロックをよけて、コインを集めるブラウザゲームです。スマホでもPCでも遊べます。

## 遊び方

- **赤いブロック**に当たるとゲームオーバー
- **コイン**は +50点。連続で取る(2.2秒以内)とコンボになり、倍率が上がります(最大×5)
- 生き残るほど加点されます(1秒で +10点)
- 15秒ごとにレベルアップして、どんどん速くなります
- ブロックは落ちてくる少し前に、画面の上に赤い警告が出ます

## 操作方法

| 端末 | 操作 |
| --- | --- |
| PC | `←` `↑` `↓` `→` または `W` `A` `S` `D` で移動 / `P` ポーズ / `M` ミュート / `Space` スタート |
| スマホ | 画面のどこでも指をスライドして移動 |

## ファイル構成

```
index.html   画面の骨組みと、ルール・操作説明
style.css    見た目とアニメーション
script.js    ゲーム本体(動き・当たり判定・効果音)
```

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る(例: `void-runner`)
2. この 4 つのファイルをリポジトリの一番上の階層にアップロードする
3. リポジトリの **Settings → Pages** を開く
4. **Source** を `Deploy from a branch`、Branch を `main` / `(root)` にして Save
5. 数分後に `https://ユーザー名.github.io/void-runner/` で遊べるようになります

## カスタマイズ

`script.js` の先頭にある数値を変えると、遊びやすさを調整できます。

- `LEVEL_TIME` … 何秒ごとにレベルアップするか
- `COMBO_TIME` … コンボが続く秒数
- `SENS` … スマホの指の動きに対する自機の動きやすさ
