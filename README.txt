Void Runner(軽量版)
====================
void-runner/      ← 公開用(コメントや空白を削った軽い版。これをGitHubに置く)
source-readable/  ← 編集用(コメント付きの読みやすい版。直すときはこっちを編集)

■ GitHubで更新版を公開する(ブラウザだけでOK)
 1. 自分のリポジトリを開く
 2. Add file > Upload files を押す
 3. void-runner フォルダの中の3ファイル(index.html / style.css / script.js)をドラッグ
    ※同じ名前のファイルは上書きされます
 4. 下の Commit changes を押す
 5. 1〜2分待つ(Settings > Pages の上に緑のチェックが出れば反映済み)
 6. サイトを開いて Ctrl+Shift+R(Macは Cmd+Shift+R)で強制再読み込み

■ 古いままのとき
 ・index.html の ?v=2 を ?v=3 のように変えて再アップロードすると、必ず新しい版が読まれます。
 ・Actions タブでデプロイが成功しているか確認。

■ データ
 ハイスコア・ランキングは各端末のブラウザに保存されます(更新しても消えません)。
